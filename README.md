# 一池 / Yichi 1.6

原生 macOS 金鱼动态桌面。AppKit 负责桌面窗口和菜单栏，SpriteKit 负责鱼群动画，SwiftUI 负责中文控制面板。纯色、透明图形与细颗粒材质构成画面，不使用渐变色。无联网行为、第三方依赖或个人文件访问。

## 本次更新

- 遮挡即暂停：每块屏幕各自判断桌面窗口是否"看得见"——被全屏应用完全盖住、不在当前空间、系统挂起或手动暂停时，该屏的池塘模拟与绘制整体冻结（功耗归零），窗口重新露出立即从原处续播，不跳帧。遮挡状态变化实时响应，另有每分钟一次的兜底重估，漏掉通知也不会永久冻结；预览窗口被完全遮住或最小化时同样暂停。
- 手动固定时段（非"自动"）时，每分钟一次的时段对表直接跳过，不再空转全部场景。
- 关闭"鼠标互动"时彻底卸载全局鼠标监听，开启时再装回；关闭后鼠标移动不触发任何采样。
- 池塘小居民：新增小乌龟、蝌蚪和田螺。两只小乌龟慢条斯理地巡游，四肢错拍划水，每隔十几秒上浮换气并在水面泛起一圈涟漪，也会慢慢游向饲料（不冲刺、不受惊吓）；一小群蝌蚪抱团游弋、时不时猛窜一下，急挥光标惊散鱼群时也四散弹开；田螺贴着池底慢慢爬，爬一阵歇一阵，靠边时缓慢折返。三者与金鱼同一套画法（纯色形状、细线、颗粒纹理，独立 4 倍高清纹理缓存），随时段光色一起染色，可用设置里"小乌龟与小邻居"开关整体关闭。
- 时段光色：池塘随一天的时间变化——凌晨清冷微蓝、中午保持各主题原色、傍晚染上金黄、夜晚沉暗泛月光；池水、池底烘焙、植物、金鱼与水面反光一起切换，菜单栏壁纸同步更新。默认跟随本地时钟（4–10 点凌晨、11–16 点中午、17–19 点傍晚、其余晚上），也可在设置的"时间光线"里固定某一时段；切换时段时池底按缓存签名重建一次，其余时刻零开销。

- 水面改为安静、稀疏的反光：移除全屏网状光纹，按屏幕面积仅保留 4–12 处短反光，各自缓慢漂移、变淡；池底保留轻微折射，不自动生成随机同心圆。鱼尾波改得更疏、更轻。鼠标与投喂仍产生大范围涟漪。
- 荷叶、睡莲、花朵与浮萍随水流轻漂和微转，邻近植物共享缓慢水流，每株还有不同节奏；漂移围绕原群落，不会游离池边。沉水草采用局部网格变形，根部固定、叶梢弯动。涟漪经过时轻推浮叶。植物和水面一起暂停，并响应系统“减少动态效果”；不使用渐变、模糊或辉光。
- 优化从全屏应用三指滑回桌面的显示：桌面窗口在显示前先准备完整池塘底图，透明动态画布恢复绘制时保留底图；窗口可参与全屏空间。菜单栏融合也使用完整池塘壁纸；进入其他空间时识别并替换旧版绿色壁纸，不改动其他空间的用户壁纸。底图只在主题、视野、植被或金鱼外观变化时生成，每屏交替复用两张壁纸图片。
- 新增鼠标互动：光标缓缓拂过水面时沿途泛起涟漪，附近的金鱼会好奇靠近、游近后停驻端详；快速挥动光标会惊散一片鱼群，受惊的鱼急转加速逃离，片刻后恢复悠游。
- 按住修饰键（默认 ⌥，可在设置里换成 ⌃/⇧/⌘）轻点桌面空白处才投喂：不加按键的普通点击完全不触发，避免与桌面的框选、多选等系统操作冲突。判定仍要求点击落在所有可交互的普通窗口之外，桌面图标与程序坞照常响应；程序坞那块铺满整屏、忽略鼠标的背景窗口不算遮挡，否则任何位置都判不成桌面。
- 多处投喂可以并存：再点别处不再清除上一把饲料，最多同时保留 5 处，再投时替换最早的一处；每尾金鱼扑向离自己最近的一处，饲料约 16 秒后自行消散。
- 金鱼抢食更有戏：每尾先认准离自己最近的一处饲料、半途不轻易换食；距离越远冲得越猛（最高约为平时游速的 3 倍），临近饲料才收速，钻进饲料群里啄食。快速挥动光标惊散鱼群时，鱼先猛地弹开（瞬间约为平时 7 倍速度）再在 1.4 秒内缓缓收势。
- 预览窗口点击投喂改用相机世界坐标换算，视野拉远时饲料准确落在点击处。
- 重绘高清荷叶、缺口睡莲叶、粉色/乳白睡莲、带状水草、沉水叶茎及浮萍；每种植物采用独立 4 倍分辨率纹理，加入细叶脉、叶缘、斑点、水珠与花瓣细节，避免全景纹理缩小造成模糊。
- 植物尺寸明显增大，分布从四个边角扩展到池边与三处池内植被群；水草位于鱼群下方，浮叶与花朵位于水面上方，中央保留开阔水域。丰茂度改变时保留已有植物的位置。
- 菜单栏融合：开启桌面池塘时临时将系统壁纸替换为池塘画面，顶部菜单栏随池塘主题变色；关闭融合、关闭桌面或退出时自动恢复原壁纸及其显示选项。
- 视野默认拉远到 1.65 倍，可在 1–2.4 倍间调节。鱼、植物、水波及投喂位置使用一致的世界坐标。
- 池底加入不规则淤泥、砂砾、卵石、细颗粒和水光线条。
- 池边和池内的浮叶、睡莲、水草及浮萍丰茂度可调。
- 新增单尾金鱼画室：鱼身色、鱼鳍色、名称、45%–200% 大小、自由画笔、橡皮、笔刷粗细、起始花纹、撤销、重做、清空和恢复。
- 每尾金鱼的外观自动保存并同步到所有桌面和预览，调整鱼群数量后仍保留对应金鱼的设计。

## 构建与运行

需要 macOS 13 以上及 Apple Command Line Tools。

```sh
./build.sh
open build/一池.app
```

`build/一池.app` 包含 arm64 和 x86_64 两种架构。日常开发可用 `--dev` 只编译本机架构、跳过 lipo，明显加快迭代；可与输出目录参数组合：

```sh
./build.sh --dev
./build.sh --dev /absolute/path/to/output
```

构建采用本地签名；向其他电脑公开分发时，需另外配置 Apple Developer ID 签名与公证。

## 使用

通过菜单栏金鱼图标控制桌面；从"金鱼画室"进入编辑器，选择左侧金鱼，在中间鱼身上拖动绘制。修改会自动保存，点击"回到池塘"返回预览。更改鱼身或鱼鳍颜色时，点颜色方块展开纯色色板；也可输入六位十六进制色号选择任意颜色。"一汪池水"里可在自动与凌晨/中午/傍晚/晚上之间切换时间光线，状态行会显示当前时段。"池塘里的居民"里的"小乌龟与小邻居"开关控制乌龟、蝌蚪和田螺是否出场。

快捷键：⌘1 池塘预览，⌘2 金鱼画室，⌘, 设置，⌘Q 退出。绘制画布获得焦点时，⌘Z 撤销、⇧⌘Z 重做。真实桌面不拦截鼠标：鼠标互动通过系统事件监听在旁观察实现，桌面图标、右键菜单与程序坞不受影响；光标缓动泛涟漪、急挥惊散鱼群、按住修饰键轻点桌面空白处投喂（默认 ⌥，设置里可换），均可在设置里用“鼠标互动”开关关闭。

配置保存在本机 UserDefaults，键包含 `fishCount`、`swimSpeed`、`waterTheme`、`desktopEnabled`、`lowPower`、`viewDistance`、`plantDensity`、`menuBarHarmony`、`mouseInteraction`、`feedModifier`、`daylightMode`、`pondCritters` 和 `fishDesigns`。画室从旧版本配置自动补充默认值，不会清除已有设置。

## 验证

```sh
build/一池.app/Contents/MacOS/PondDesktop --self-test
build/一池.app/Contents/MacOS/PondDesktop --render-preview /absolute/path/to/pond.png
build/一池.app/Contents/MacOS/PondDesktop --render-preview /absolute/path/to/pond.png --daylight dusk
build/一池.app/Contents/MacOS/PondDesktop --render-matrix /absolute/path/to/dir
```

`--render-preview` 输出当前偏好下的单张 1440×900 高清预览，`--daylight` 可临时指定 dawn/noon/dusk/night 之一对比时段光色（不写入真实设置）；`--render-matrix` 用隔离偏好一次性渲染青池/墨池/晴池 × 1.00/1.65/2.40 视野 × 疏朗/自然/丰茂共 27 张截图（固定中午光色，便于跨版本对比），并生成 index.html 拼览页，全程不触碰真实设置与壁纸。

自检使用独立偏好域，不修改真实鱼群外观或系统壁纸。它验证 60 尾鱼在 3 档速度及 3 种屏幕尺寸下连续模拟 60 秒的边界、有限值和转向速度，以及暂停恢复、投喂、单尾外观持久化、画笔裁切、橡皮恢复底色、撤销重做、鱼群纹理更新、相机缩放、零尺寸窗口保护及池塘壁纸的提前生成、相机一致性、屏幕比例、不透明底色、高清 PNG 和双文件复用；交互部分验证涟漪节流、急挥惊散只触发一次、轻点与拖拽区分、桌面空白判定、光标世界坐标换算、好奇靠近与受惊逃逸；时段部分验证全天映射、中午恒等、夜晚更暗更冷、傍晚偏暖、池底压暗烘焙与鱼/浮叶/反光的时段染色；小动物部分验证乌龟换气与认食、蝌蚪群落与受惊四散、贴图挂载、暂停、开关清场、视野缩放与时段染色。

## 源码结构

- `Sources/Daylight.swift`：四个时段的光色定义、本地时钟映射与调色板染色。
- `Sources/Pond.swift`：设置、鱼群运动、世界坐标与桌面/预览窗口。
- `Sources/PondInteraction.swift`：光标事件流、涟漪/惊吓/轻点判定与桌面空白检测。
- `Sources/WallpaperSync.swift`：桌面切换与菜单栏融合用的池塘壁纸生成、缓存及原壁纸保存/恢复。
- `Sources/DesktopPresentation.swift`：窗口内常驻池塘底图和透明 SpriteKit 画布，覆盖渲染恢复空档。
- `Sources/FishArtwork.swift`：金鱼外观数据、笔画数据、材质绘制及鱼鳍动画。
- `Sources/PondCritters.swift`：小乌龟、蝌蚪与田螺的纹理绘制、运动行为与容器管理。
- `Sources/FishEditor.swift`：单尾编辑器、画布输入、撤销重做及自动保存。
- `Sources/PondEnvironment.swift`：池底和水生植物的程序化绘制。
- `Sources/PondWater.swift`：轻微水面折射、稀疏局部反光与有数量上限的大范围涟漪。
- `Sources/PlantArtwork.swift`：独立高清植物纹理、植物细节绘制和纹理缓存。
- `Sources/PlantMotion.swift`：浮叶漂移与微转、花朵/浮萍运动、根部固定的水草弯动。
- `Sources/Checks.swift`：外观编辑及缩放回归检查。
- `Sources/main.swift`：应用入口。

静态景物和鱼身缓存为纹理；运行时更新鱼的位置和鳍的旋转。外观相同的金鱼共享同一套 GPU 纹理，60 尾默认鱼群只需 4 套鱼身纹理；池底与植物按主题、时段、丰茂度、屏幕尺寸和 0.125 档视野分桶重建，拖动滑块时池底直接拉伸复用，不再逐档重烘焙。默认 30 fps，节能模式 20 fps，休眠和会话切换时暂停；每块屏幕的桌面窗口被全屏应用完全遮挡或不在当前空间时，该屏场景一并冻结，重新可见立即续播。桌面窗口处于系统桌面图层上方、图标下方，忽略鼠标。

反光和波峰纹理在各个屏幕与预览之间共享。水面只保留轻微池底折射和少量局部反光，不使用全屏光纹纹理；最多三处最近的涟漪影响池底折射及浮叶。植物每帧只更新位置、角度和水草的少量网格顶点，复用原来的高清纹理。自检比较真实渲染像素，验证动态折射生效、反光稀疏、涟漪范围、节点上限和消散清理、无关设置变更保留进行中的涟漪、视野变化重建水面，以及六类植物的运动、长时间漂移范围、茎根固定、暂停和减少动态效果。

鼠标互动建立在“旁观察”上：全局 `NSEvent` 监听不消费事件、无需辅助功能权限，随"鼠标互动"开关装卸（关闭后不采样任何鼠标事件），移动采样只做坐标换算并按路程与时间双重节流泛涟漪（缓动 <240 pt/s），急挥（>800 pt/s）在冷却期内只惊散一次；光标位置换算进各屏池塘的世界坐标，好奇力为食物吸引力的三分之一、游近 70 单位内即停驻。桌面投喂在松开时判定：按下时必须按住投喂修饰键（默认 ⌥，设置可换 ⌃/⇧/⌘），松开时按住需小于 0.35 秒且位移小于 6 pt（排除框选与拖拽），且点击落在所有 layer ≥ 0 的在屏窗口（应用窗口、程序坞、菜单栏）之外——桌面图标位于桌面层级，不参与拦截，点击图标时文件照常打开，鱼群只会顺路游过。程序坞铺满整屏的鼠标穿透背景窗口按所有者（com.apple.dock）与面积排除，不计入遮挡；判定不要求特定前台应用。

macOS 菜单栏的半透明底色只取样系统壁纸、不含桌面图层窗口；全屏与桌面切换时，系统也会先显示壁纸。因此“菜单栏融合”使用当前池塘的一帧高清画面作为临时壁纸，裁切范围与相机视野一致；缓存签名包含屏幕、主题、视野、植被和金鱼外观，游动、暂停、投喂与速度调整不重复生成。每屏在 `~/Library/Application Support/一池/` 交替复用两张 PNG，让系统刷新图片并控制磁盘占用。原壁纸路径与显示选项按屏幕记录在 `savedWallpapers`，关闭桌面、关闭融合或退出应用时恢复；升级时沿用旧版纯色壁纸保存的原图记录。静态壁纸中的鱼位置可能与接上的动态鱼群略有差异。

壁纸实际按桌面空间保存，启动时更新当前空间不代表其他空间同时更新；空间切换通知会将当前空间中一池自己生成的旧壁纸更新为池塘画面。桌面窗口本身还常驻同一帧高清底图，独立于菜单栏融合开关；SpriteKit 采用透明底色，首次显示前就准备好底图，渲染器被遮挡或恢复时也不会露出窗口的绿色底色。自检覆盖底图缓存、外观更新、移除动态渲染器后仍保留池塘画面，以及可见性暂停门控的判定。

## 验证范围

Apple 芯片 / macOS 15.5 已运行验证；Intel 版本已编译，未在 Intel 硬件上测试。多屏实现保留，仍需更多硬件验证。植物和水底采用带材质细节的绘制风格；不是实拍背景。macOS 桌面层级行为需随系统升级验证。
